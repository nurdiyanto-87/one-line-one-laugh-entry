A one-line joke for make.fun's "One Line, One Laugh" bounty: the office
printer that only ever jams on documents marked urgent — because it
unionised while everyone was at lunch.

`main.py` (pure Python standard library) writes the line to
`/output/entry.txt` — one line, 132 characters, valid UTF-8.

## Run it

```sh
python3 main.py
```
